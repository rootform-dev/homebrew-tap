# Rootform Homebrew tap

Install the Rootform CLI on macOS with Homebrew:

```sh
brew install rootform-dev/tap/rootform
rootform version
```

This formula downloads the published
[Rootform v0.1.1 release](https://github.com/rootform-dev/rootform/releases/tag/v0.1.1).
Homebrew checks the archive's SHA-256 before installing the CLI. Apple Silicon
and Intel Macs use separate release archives. The installed archive includes
the binary license, third-party notices, SPDX SBOM, and release checksums.

A tap is a Homebrew package repository; formulae and casks are package types.
This tap provides a formula for the Rootform CLI. Homebrew manages its updates
and uninstallation like other formulae.

To remove Rootform:

```sh
brew uninstall rootform-dev/tap/rootform
```

## Maintainers

`Formula/rootform.rb` is generated by `scripts/generate-installation.ts` in the
[Rootform distribution repository](https://github.com/rootform-dev/rootform).
Generate it from a complete, published release directory only after verifying
its manifest and `SHA256SUMS`. Keep the release archive URLs and SHA-256 values
tied to that exact release. Qualify installation on both supported macOS
architectures before changing this tap.

Tap source is Apache-2.0. Distributed Rootform binaries are Elastic License 2.0;
the release archive carries its license and third-party notices.
