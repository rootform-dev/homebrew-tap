# Rootform Homebrew tap

This tap provides the Rootform CLI formula for macOS.

Install and remove Rootform with:

```sh
brew install rootform-dev/tap/rootform
brew uninstall rootform-dev/tap/rootform
```

The formula downloads the archive of one published Rootform release, and
Homebrew checks its SHA-256 before installing the CLI. Apple Silicon and Intel
Macs use separate release archives. The installed archive includes the binary
license, third-party notices, SPDX SBOM, and release checksums.

A tap is a Homebrew package repository; formulae and casks are package types.
This tap provides a formula for the Rootform CLI. Homebrew manages its updates
and uninstallation like other formulae.

## Maintainers

`Formula/rootform.rb` is generated by `scripts/generate-installation.ts` in the
[Rootform distribution repository](https://github.com/rootform-dev/rootform)
and attached to the installation metadata artifact of the qualification run
that the publish workflow names. Add it here through a pull request only after
that release is published, keeping the archive URLs and SHA-256 values tied to
that exact release. Qualify installation on both supported macOS architectures
before changing this tap.

Tap source is Apache-2.0. Distributed Rootform binaries are Elastic License 2.0;
the release archive carries its license and third-party notices.
